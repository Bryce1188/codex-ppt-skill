# 常见问题与具体修复

“自然”以内容具体、图表可靠、视觉服务讲述来判断；不承诺通过 AI 检测器。

| 发现的问题 | 修复动作 | 复查依据 |
| --- | --- | --- |
| 放到任何项目都通用的空话 | 用任务、实现选择和已有结果替换；无资料就删去夸大结论 | 每个成果能指向证据 |
| 标题都是“背景/优势/总结” | 有证据的结果页写出主要发现；规定章节名保留 | 标题与该页证据一致 |
| 每页都是三张圆角卡片 | 按证据改为大图、比较、流程、表格或简短说明 | 全稿缩略图与逐页预览 |
| 段落堆满、字号不断变小 | 减少重复，把解释放备注，必要时拆页 | 投影尺度下可读，不删限制 |
| 生图文字错字、无法改动 | 背景无文字，标题与正文用原生对象 | 从最终 PPTX 提取并修改文字 |
| 假截图、界面与项目不符 | 换真实捕获或明确标记无截图 | 捕获记录＋图片散列＋查看原图 |
| 漂亮图表但数值错 | 用来源数据建立原生图表，核对单位、分母和比较条件 | 数据文件、图表数值和工作簿 |
| 背景抢内容或太暗 | 内容区降低细节，纯色衬底；同时检查浅/深色文字 | 实际文字叠加后的样页 |
| 每张图片像来自不同作品 | 固定主题色、材质、光线和参考图，修改局部 | 代表页对照，不只看封面 |
| 颜色承担全部含义 | 加文字、线型、标记和直接标签 | 灰度仍能区分，图像有 alt |
| 导出后溢出、字体替换 | 使用环境存在的字体，重新排版并检查最终文件 | 包结构检查＋导入渲染；未在 PowerPoint 验证需说明 |
| 小改动导致整套重做 | 固定其余页的内容/数据/素材，仅改受影响页 | 对照修改前后页和全稿风格 |
| 引用丢失、结论比证据强 | 来源进对应页备注，关键限制保留在页内 | 要求—证据—页面逐项核对 |

依据与原始链接见 [调研记录](research-provenance.md)。最终复查需要同时检查内容、对象结构和实际渲染，任何单项通过都不能代替其他检查。
