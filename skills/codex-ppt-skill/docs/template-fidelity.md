# 模板保真

只有用户明确把已有 PPT 当模板时才匹配其设计；只作为资料来源的 PPT 不自动成为模板。

先渲染代表页并检查原生对象、母版、布局、字体和比例。记录文字替换位置和允许改动的对象。普通替换保留原图、图表、母版、位置与同级字号；超长文案先精简或换兼容的页面，不把所有标题缩小。

数据图表同时更新数据和图形，特别检查“只改百分比数字但进度弧没变”的情况。固定形状图不是原生 chart，不能承诺自动同步。

仅作必要改动，另存新文件，对比原始与输出的实际渲染。导入器将图表或复杂对象扁平化时不能称完整保真。不得为追求模板丰富度复制第三方未授权模板，也不把他们的非商业素材混入自己的通用分发包。
