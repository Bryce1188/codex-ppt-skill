# 图片后端选择

仅在 `image` 路线或确实需要生成 `hybrid` 视觉素材时读取。`editable` 数据页不需要为了满足流程去调用生图。

先核实当前可调用的工具，优先使用宿主内置图片工具；模型身份以真实工具元数据为准，不能把工具名或订阅自动等同于某个模型。

内置工具不可用、缺必需能力，或用户指定 API/CLI 时，才考虑 `scripts/image_gen.py`。沿用已授权的后端与既有有效配置，不因方便批处理而换后端。只要已获任务授权，普通内部样页不额外问一次后端确认；用户指定逐步确认时遵守该节点。

API/CLI 具体运行方式见 [fallback](cli-api-fallback.md)。缺失配置或鉴权报错后再读 [配置](image-model-configuration.md)。不要输出密钥，或把生图配置加入交付压缩包。

缺少生图能力时：非必需视觉用现有合法素材或清晰的原生页面继续；用户明确要求的生图效果不能伪造，说明局部限制。禁止用 HTML/PPT 截图冒充生图后端输出。
