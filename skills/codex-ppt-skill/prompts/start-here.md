# 不需要专业术语的启动提示词

直接复制适合的例子，把方括号换成你的材料；拿不准的部分可以省略。Skill 会先读材料，再补问会影响结果的细节。

## 一句话开始

```text
用 $codex-ppt-skill，根据这份要求和我的项目做一份可编辑 PPT。用途是[课堂汇报/答辩/演示]，大约讲[时间]。先读材料，缺什么再问我；自动整理内容、真实截图和背景，最后检查并交付。
```

## 老师任务＋完成的项目

```text
用 $codex-ppt-skill 做课程汇报。
老师要求：[附件或路径]
项目：[项目路径]
目的：向老师说明我做了什么、怎样实现、结果如何。
先从材料里识别要求和已完成部分，必要时用本机 Superpowers 问我关键细节。
把真实运行截图、结果图和数据放到对应页面；没有证据的内容标明缺口。
背景按项目选择，文字和数据保持可编辑。自动应用 Humanizer，给我 PPTX 和预览。
```

## 我想先选风格

```text
用 $codex-ppt-skill 做这份汇报。先用相同的真实内容做 2–3 种风格样页，至少包含一张结果页，让我选。选定后沿用整套风格；不要因为我还没回复就替我选择。
```

## 按现有模板制作

```text
用 $codex-ppt-skill，把这些材料放进我给的 PPT 模板。先看模板实际页面，保留模板布局、字体和页脚。内容不足时告诉我，文字、图表尽量保持可编辑，另存新文件。
```

## 直接做初稿

```text
用 $codex-ppt-skill 直接做初稿，普通设计细节你来决定并简短记录假设。老师的硬性要求照做，缺少事实就标注，不补编；只有影响正确性的关键信息才问我。
```

## 修改已经完成的 PPT

```text
只改第[页号]页：[具体改动]。保留其他页的内容和顺序。
背景改成[更浅/减少装饰/换成我上传的图]；保留原生文字、数据、真实截图和来源。改完检查受影响页面及整套风格。
```

## 想把背景中的形状也分别修改

```text
用 $codex-ppt-skill，背景也要在 PowerPoint 中逐个修改形状和颜色。优先使用原生形状或可编辑矢量，不用整张生成图片代替。照片可以单独替换。
```

内部执行规则见 [需求与 Superpowers](../docs/intake-and-superpowers.md)；无需让用户填写内部 JSON。

## 软件项目工作汇报

```text
用 $codex-ppt-skill，根据这个项目做工作汇报 PPT：[项目路径]。
听众是[老师/项目负责人/技术团队]，目的是[展示成果/答辩/汇报进度]，
大约讲[时长]，重点展示功能、整体架构和数据库设计。
先读当前代码和已有材料，发现旧文档冲突时核对实现。
用真实界面做功能页，架构和表关系做成可编辑图示。
先试做代表性内页并检查效果，再展开全稿。
普通配色和排版你决定，只问会影响内容的缺项。
自动应用 Humanizer，保留未测试范围，不编造性能提升。
```
